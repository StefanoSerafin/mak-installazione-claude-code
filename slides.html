Come facciamo oggi

  1. Apri VS Code nella tua cartella Claude Workspace.

La verifica

Si incolla nel pannello di Claude, in VS Code:

Controlla che il mio computer sia pronto per il corso di Claude Code. Esegui tu i comandi che servono, senza installare né modificare nulla. Alla fine mostrami solo una tabella con tre colonne (Cosa, Versione o stato, OK?) per: Claude Code; Git; VS Code (se il comando code non risponde, controlla se l'app è installata: su Mac in /Applications, su Windows nella cartella Programs di AppData\Local); le estensioni di VS Code anthropic.claude-code, tomoki1207.pdf, pomdtr.excalidraw-editor e vscode-icons-team.vscode-icons (con code --list-extensions oppure, se code non risponde, guardando la cartella .vscode/extensions nella cartella utente); Homebrew se sono su Mac oppure Chocolatey se sono su Windows; Pandoc; FFmpeg; whisper.cpp; Node.js; il motore per i PDF (BasicTeX su Mac, MiKTeX su Windows); GitHub CLI e login a GitHub; il file CLAUDE.md di questa cartella (OK solo se non contiene più parti tra [[ ]]); le skill messaggio-settimanale, riassunto-visita e nuovo-tool nella cartella .claude/skills. Sotto la tabella, per ogni riga che non è OK, scrivi in una frase cosa devo fare.

Dove ci si blocca di solito

Mac

  • command not found: claude: manca il PATH (due comandi nella guida)
  • command not found: brew: saltati i «Next steps» di Homebrew
  • VS Code non vede un programma appena installato: chiudi e riapri VS Code

Windows

  • 'claude' is not recognized: manca %USERPROFILE%\.local\bin nel PATH
  • 'irm' is not recognized: sei nel Prompt dei comandi, non in PowerShell
  • Chocolatey: PowerShell va aperta «come amministratore»

E adesso si lavora

  • Come si parla a Claude: il risultato e il contesto, non i passaggi.
  • Il tuo CLAUDE.md: cosa sa Claude di te e dei tuoi clienti.
  • Le skill: le cose che fai ogni settimana diventano un comando.
  • Primo tool: da un tuo Excel a una pagina da consultare dal telefono.

Livello 2

I siti e il tuo second brain

Dopo l'installazione: Claude copia e legge i siti MAK, e con quel materiale costruisce il tuo wiki personale da consultare in Obsidian. Si fa in più giorni, una fase alla volta.

Come funziona

  1. Siti/: Claude copia e legge i siti NPK, MATE, MAK, TRK e il sito agenti.
  2. Second Brain/: con quelle copie scrive il tuo wiki, un marchio alla volta (metodo di Karpathy).
  3. Obsidian: il wiki si sfoglia come un sito; a Claude si fanno domande e risponde citando le pagine.
  4. Un lavoro lungo per conversazione, poi /clear: Claude resta preciso e il piano Pro basta.

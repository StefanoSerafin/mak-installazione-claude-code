Fase 0 Prima di cominciare

Abbonamento attivo e computer adatto, prima di installare qualsiasi cosa.

Claude Code chiede macOS 13 o più recente; Homebrew (fase 6) è pensato per macOS 15 o più recente.

  1. Menu Apple (la mela in alto a sinistra) → «Informazioni su questo Mac»: leggi la versione di macOS (deve essere 13 Ventura o più recente).
  2. Tieni a portata di mano la password con cui sblocchi il Mac: verrà chiesta più volte.
  3. Mettiti con 60–90 minuti liberi e una connessione stabile (meglio Wi-Fi di casa che hotspot del telefono).

Cosa devi vedere macOS 13 o superiore. Con macOS 15 Sequoia o più recente sei a posto per tutto.

Se non va
  • Il Mac ha macOS 12 o più vecchio — Aggiorna macOS da Impostazioni di Sistema → Generali → Aggiornamento Software prima di andare avanti. Se il Mac non si aggiorna, scrivi a Stefano.
  • Il Mac ha macOS 13 o 14 — Claude Code va bene. Homebrew non è ufficialmente supportato ma di solito funziona: vai avanti e, se alla fase 6 dà errore, scrivi a Stefano.

Fonte: code.claude.com/docs/en/setup

  2. Per incollare un comando: ⌘ + V, poi Invio.

Fase 2 Git

Lo strumento che tiene le versioni dei file: Claude Code lo usa di continuo.

Su Mac Git arriva con gli «strumenti da riga di comando» di Apple. Servono anche a Homebrew.

  1. Incolla il comando nel Terminale e premi Invio.
  2. Si apre una finestra: clicca «Installa», poi «Accetto» sulla licenza. Ci vogliono 5–15 minuti.
  3. Finita l'installazione, nel Terminale scrivi git --version e premi Invio.
Comando
xcode-select --install

Cosa devi vedere git --version risponde con una riga del tipo «git version 2.50.1 (Apple Git-…)».

Se non va
  • Compare «command line tools are already installed» — Sono già installati: vai al passo successivo.
  • La finestra dice che il software non è disponibile o il download si blocca — Controlla la connessione e riprova. Se si blocca ancora, salta: Homebrew (fase 6) li installa da solo. Avvisa Stefano.

Fonte: git-scm.com/downloads/mac

Fase 3 Claude Code

Installare Claude Code e collegarlo al proprio abbonamento.

È il comando ufficiale di Anthropic. Claude Code poi si aggiorna da solo.

  1. Incolla il comando nel Terminale e premi Invio. Durante lo scaricamento non si vede nessun avanzamento: aspetta che torni il %.
  2. Chiudi il Terminale (⌘ + Q) e riaprilo.
  3. Scrivi claude --version e premi Invio.
Comando
curl -fsSL https://claude.ai/install.sh | bash

Cosa devi vedere Un numero di versione, per esempio «2.1.226 (Claude Code)».

Se non va
  • «zsh: command not found: claude» — La cartella di Claude non è nel PATH (l'elenco dei posti dove il Mac cerca i programmi). Incolla questi due comandi, poi riprova claude --version:
    Comando
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
  • «zsh: permission denied: …/.zshrc» — Il file delle impostazioni è bloccato. Incolla il comando, poi ripeti i due comandi del caso precedente:
    Comando
    chmod u+w ~/.zshrc
  • «syntax error near unexpected token '<'» oppure un errore 403 — La rete blocca lo scaricamento (succede con alcune reti aziendali o pubbliche). Riprova da casa o da un'altra connessione; se l'errore resta, scrivi a Stefano.

Fonte: code.claude.com/docs/en/troubleshoot-install

Collega Claude Code al tuo abbonamento Pro.

  1. Nel Terminale scrivi claude e premi Invio.
  2. Scegli il tema (chiaro o scuro) con le frecce e Invio.
  3. Scegli l'accesso con l'account Claude (abbonamento), non con la «Console» o le API.
  4. Si apre il browser: entra con il tuo account e clicca «Autorizza». Torna al Terminale.
  5. Esci da Claude scrivendo /exit e premendo Invio.
Comando
claude

Cosa devi vedere Dopo il login, il messaggio di benvenuto di Claude Code e la riga in cui scrivere.

Se non va
  • Il browser non si apre — Nel Terminale premi il tasto c: l'indirizzo di accesso viene copiato. Incollalo nel browser e completa il login.
  • «OAuth error: Invalid code» — Il codice è scaduto. Premi Invio per riprovare e completa il login subito dopo l'apertura del browser.
  • «API Error: 403» dopo il login — L'abbonamento non risulta attivo: controlla su claude.ai/settings che il piano sia Pro, poi riprova.

Fonte: code.claude.com/docs/en/troubleshoot-install

Cosa devi vedere Nel Terminale, code --version risponde con un numero di versione.

Fase 6 Il gestore dei programmi

Il negozio di programmi da riga di comando da cui Claude prende quello che gli serve.

Homebrew installa con un comando i programmi che servono alle skill (per esempio Pandoc per i documenti, ffmpeg per i video). Poi è Claude a usarlo.

  1. Incolla il comando nel Terminale e premi Invio.
  2. Ti chiede la password del Mac (non vedrai i caratteri) e poi di premere Invio per confermare. Ci vogliono alcuni minuti.
  3. Importante: alla fine compare la sezione «Next steps» con due o tre comandi. Copiali ed eseguili uno alla volta, esattamente come sono scritti.
  4. Chiudi e riapri il Terminale e scrivi brew --version.
Comando
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Cosa devi vedere brew --version risponde con «Homebrew» e un numero di versione.

Se non va
  • «zsh: command not found: brew» — Hai saltato i «Next steps». Sui Mac con chip Apple incolla questi due comandi, poi riprova:
    Comando
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
  • Chiede di installare gli strumenti da riga di comando — Conferma e lascia finire: è il passo Git che non era andato a buon fine.

Fonte: docs.brew.sh/Installation

È il modo in cui lavorerai davvero: dici a Claude cosa ti serve e lui installa lo strumento con Homebrew.

  1. In VS Code, nel pannello di Claude, scrivi: Sono su Mac e ho Homebrew. Installa Pandoc e trasforma il file di testo che hai creato in un documento Word.
  2. Quando Claude chiede il permesso di eseguire il comando di installazione, accetta.
  3. Se preferisci farlo a mano, il comando per il Terminale è qui sotto.
Comando
brew install pandoc

Cosa devi vedere Nella cartella compare un file .docx che si apre con Word o Pages.

Se non va
  • Claude dice che brew non esiste — Chiudi e riapri VS Code (prende il PATH all'avvio), poi ripeti la richiesta.

Fonte: docs.brew.sh/Installation

Fonte: cli.github.com/

Con GitHub CLI Claude può salvare e pubblicare il lavoro senza che tu debba scrivere password.

  1. Nel Terminale incolla brew install gh e premi Invio.
  2. Poi scrivi gh auth login e rispondi così: GitHub.com → HTTPS → Yes (authenticate Git) → Login with a web browser.
  3. Il Terminale mostra un codice di 8 caratteri: copialo, premi Invio, incollalo nella pagina che si apre e clicca «Authorize».
  4. Controlla con gh auth status.
Comando
brew install gh
gh auth login

Cosa devi vedere gh auth status risponde «Logged in to github.com account …».

Se non va
  • Il browser non si apre — Apri a mano github.com/login/device e incolla il codice.

Fase 3 Claude Code

Installare Claude Code e collegarlo al proprio abbonamento.

È il comando ufficiale di Anthropic per PowerShell. Claude Code poi si aggiorna da solo.

  1. Incolla il comando in PowerShell e premi Invio. Durante lo scaricamento non si vede nessun avanzamento: aspetta che torni il prompt.

Comando

Se non va

Incolla queste due righe in PowerShell, chiudi e riapri PowerShell, poi riprova claude --version. In alternativa, a mano: Impostazioni → cerca «variabili d'ambiente» → «Modifica le variabili d'ambiente relative al tuo account» → Path → Modifica → Nuovo → %USERPROFILE%\.local\bin → OK.
    Comando
    $currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

    Comando
    Remove-Item -Recurse -Force "$env:USERPROFILE\.claude\downloads"

  3. Clicca «✻ Claude Code» in basso a destra (o l'icona a scintilla). La prima volta clicca «Sign in» e completa il login nel browser.

  5. Poi: Crea un file di testo con le cose che puoi fare per me. Quando chiede il permesso di creare il file, accetta.

Fase 6 Il gestore dei programmi

Il negozio di programmi da riga di comando da cui Claude prende quello che gli serve.

Chocolatey è per Windows quello che Homebrew è per Mac: installa con un comando i programmi che servono alle skill (Pandoc, ffmpeg…). Poi è Claude a proportelo.

  1. Premi il tasto Windows, scrivi PowerShell, tasto destro su «Windows PowerShell» → «Esegui come amministratore» → Sì.
  2. Incolla il comando (è una riga sola, lunga: copiala tutta con il pulsante «Copia») e premi Invio. Il comando consente l'esecuzione dello script solo per questa finestra.
  3. Aspetta che finisca, poi chiudi PowerShell, riaprila e scrivi choco --version.
Comando
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

Cosa devi vedere choco --version risponde con un numero di versione.

Se non va
  • Errori su «Access denied» o permessi — Non hai aperto PowerShell come amministratore: chiudila e riaprila con «Esegui come amministratore».
  • Errore «running scripts is disabled» o «not digitally signed» — Non hai copiato la riga intera: la parte iniziale Set-ExecutionPolicy … serve proprio a questo. Ricopiala con il pulsante «Copia».
  • «choco» non è riconosciuto — Chiudi e riapri PowerShell. Se non basta, riavvia il PC.

Fonte: chocolatey.org/install

È il modo in cui lavorerai davvero: dici a Claude cosa ti serve e lui ti dice cosa installare.

  1. In VS Code, nel pannello di Claude, scrivi: Sono su Windows e ho installato Chocolatey. Installa Pandoc e trasforma il file di testo che hai creato in un documento Word.
  2. Chocolatey vuole i permessi di amministratore: Claude ti chiederà di incollare tu il comando in una PowerShell aperta come amministratore. Fallo, poi torna da Claude e digli che hai finito.

  • Claude dice che pandoc non esiste dopo l'installazione — Chiudi e riapri VS Code (prende il PATH all'avvio), poi ripeti la richiesta.

Fonte: chocolatey.org/install

Fase 7 GitHub

Il posto online dove si salvano le versioni e si pubblicano i tool.

Su GitHub si salvano le versioni del lavoro e si pubblicano i tool come pagine web. Il piano gratuito basta.

  1. Vai su github.com e clicca «Sign up».
  2. Usa la tua email, scegli una password e un nome utente (ti suggerisco nome e cognome, senza spazi).
  3. Conferma l'email con il codice che ti arriva.

Cosa devi vedere Sei dentro github.com con il tuo nome utente in alto a destra.

Fonte: cli.github.com/

Con GitHub CLI Claude può salvare e pubblicare il lavoro senza che tu debba scrivere password.

  1. In una PowerShell aperta come amministratore incolla choco install gh -y e premi Invio.
  2. Chiudi e riapri PowerShell (normale, non serve più amministratore). Scrivi gh auth login e rispondi così: GitHub.com → HTTPS → Yes (authenticate Git) → Login with a web browser.
  3. PowerShell mostra un codice di 8 caratteri: copialo, premi Invio, incollalo nella pagina che si apre e clicca «Authorize».
  4. Controlla con gh auth status.
Comando
choco install gh -y
gh auth login

Cosa devi vedere gh auth status risponde «Logged in to github.com account …».

Se non va
  • Il browser non si apre — Apri a mano github.com/login/device e incolla il codice.
  • Chocolatey non trova il pacchetto gh — Usa winget, già presente in Windows, in una PowerShell normale:
    Comando
    winget install --id GitHub.cli

Fonte: cli.github.com/

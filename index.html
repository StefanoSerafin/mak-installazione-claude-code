Fase 0 Prima di cominciare

Un indirizzo Gmail, l'abbonamento attivo e un computer adatto, prima di installare qualsiasi cosa.

Claude Code chiede macOS 13 o più recente; Homebrew (fase 6) è pensato per macOS 15 o più recente.

  1. Menu Apple (la mela in alto a sinistra) → «Informazioni su questo Mac»: leggi la versione di macOS (deve essere 13 Ventura o più recente).
  2. Tieni a portata di mano la password con cui sblocchi il Mac: verrà chiesta più volte.
  3. Mettiti con circa due ore libere e una connessione stabile (meglio il Wi-Fi di casa che l'hotspot del telefono): alcuni programmi da scaricare sono grandi.

Cosa devi vedere macOS 13 o superiore. Con macOS 15 Sequoia o più recente sei a posto per tutto.

Se non va
  • Il Mac ha macOS 12 o più vecchio — Aggiorna macOS da Impostazioni di Sistema → Generali → Aggiornamento Software prima di andare avanti. Se il Mac non si aggiorna, scrivi a Stefano.
  • Il Mac ha macOS 13 o 14 — Claude Code va bene. Homebrew non è ufficialmente supportato ma di solito funziona: vai avanti e, se alla fase 6 dà errore, scrivi a Stefano.

Fonte: code.claude.com/docs/en/setup

Con lo stesso indirizzo Gmail per Claude e per GitHub entri con il pulsante «Continua con Google», senza password nuove da ricordare. Più avanti nel corso potrai collegare a Claude anche Gmail, Google Calendar e Google Drive.

  1. Se hai già un indirizzo Gmail usa quello, meglio se è quello che usi per il lavoro.
  2. Se non ce l'hai, crealo su accounts.google.com → «Crea un account» (5 minuti).
  3. Attiva la verifica in due passaggi su myaccount.google.com → «Sicurezza»: protegge tutti gli account che apri con Google.
  4. In tutti i passaggi che seguono, quando un sito chiede l'email, usa questo indirizzo Gmail; se compare il pulsante «Continua con Google», usa quello.

Cosa devi vedere Sai quale indirizzo Gmail userai e riesci ad aprire la posta dal computer e dal telefono.

Se non va
  • Non ricordi la password di Gmail — Su accounts.google.com clicca «Password dimenticata?» e segui la procedura di recupero con il telefono.

Fonte: support.google.com/accounts/answer/27441

Fase 1 Il terminale

Saper aprire la finestra in cui si incollano i comandi.

Le installazioni si fanno incollando un comando in questa finestra.

  1. Premi ⌘ + Spazio, scrivi Terminale e premi Invio.
  2. Per incollare un comando: ⌘ + V, poi Invio. I comandi sono quelli nei riquadri scuri: il pulsante «Copia» li copia per intero.
  3. Mentre scrivi una password nel Terminale non compare nulla, nemmeno gli asterischi: è normale. Scrivila e premi Invio.

Cosa devi vedere Una finestra con una riga che finisce con il simbolo %.

Fase 2 Git

Lo strumento che tiene le versioni dei file: Claude Code lo usa di continuo.

Su Mac Git arriva con gli «strumenti da riga di comando» di Apple. Servono anche a Homebrew.

  1. Incolla il comando nel Terminale e premi Invio.
  2. Si apre una finestra: clicca «Installa», poi «Accetto» sulla licenza. Ci vogliono 5–15 minuti.
  3. Finita l'installazione, nel Terminale scrivi git --version e premi Invio.
Comando
xcode-select --install

Cosa devi vedere git --version risponde con una riga del tipo «git version 2.50.1 (Apple Git-…)».

Se non va
  • Compare «command line tools are already installed» — Sono già installati: vai al passo successivo.
  • La finestra dice che il software non è disponibile o il download si blocca — Controlla la connessione e riprova. Se si blocca ancora, salta: Homebrew (fase 6) li installa da solo. Avvisa Stefano.

Fonte: git-scm.com/downloads/mac

Fase 3 Claude Code

Installare Claude Code e collegarlo al proprio abbonamento.

È il comando ufficiale di Anthropic. Claude Code poi si aggiorna da solo.

  1. Incolla il comando nel Terminale e premi Invio. Durante lo scaricamento non si vede nessun avanzamento: aspetta che torni il %.
  2. Chiudi il Terminale (⌘ + Q) e riaprilo.
  3. Scrivi claude --version e premi Invio.
Comando
curl -fsSL https://claude.ai/install.sh | bash

Cosa devi vedere Un numero di versione, per esempio «2.1.226 (Claude Code)».

Se non va
  • «zsh: command not found: claude» — La cartella di Claude non è nel PATH (l'elenco dei posti dove il Mac cerca i programmi). Incolla questi due comandi, poi riprova claude --version:
    Comando
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
  • «zsh: permission denied: …/.zshrc» — Il file delle impostazioni è bloccato. Incolla il comando, poi ripeti i due comandi del caso precedente:
    Comando
    chmod u+w ~/.zshrc
  • «syntax error near unexpected token '<'» oppure un errore 403 — La rete blocca lo scaricamento (succede con alcune reti aziendali o pubbliche). Riprova da casa o da un'altra connessione; se l'errore resta, scrivi a Stefano.

Fonte: code.claude.com/docs/en/troubleshoot-install

Fase 5 VS Code

È l'editor gratuito di Microsoft da cui useremo Claude Code, uguale su Mac e Windows. Il disegno mostra come sarà alla fine di questa fase.

  1. Vai su code.visualstudio.com e clicca il pulsante di download per Mac.

  4. VS Code è in inglese: i nomi dei menu e dei pulsanti in questa guida sono quelli inglesi, scritti come li vedi.

Cosa devi vedere VS Code aperto, con la schermata «Welcome».

Fase 6 Il gestore dei programmi

Il «negozio» dei programmi da riga di comando, e subito i programmi che servono per documenti, PDF, video e audio.

Homebrew installa con un comando i programmi da riga di comando che Claude usa per lavorare su documenti, PDF, video e audio.

  1. Incolla il comando nel Terminale e premi Invio.
  2. Ti chiede la password del Mac (non vedrai i caratteri) e poi di premere Invio per confermare. Ci vogliono alcuni minuti.
  3. Importante: alla fine compare la sezione «Next steps» con due o tre comandi. Copiali ed eseguili uno alla volta, esattamente come sono scritti.
  4. Chiudi e riapri il Terminale e scrivi brew --version.
Comando
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Cosa devi vedere brew --version risponde con «Homebrew» e un numero di versione.

Se non va
  • «zsh: command not found: brew» — Hai saltato i «Next steps». Sui Mac con chip Apple incolla questi due comandi, poi riprova:
    Comando
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
  • Chiede di installare gli strumenti da riga di comando — Conferma e lascia finire: è il passo Git che non era andato a buon fine.

Fonte: docs.brew.sh/Installation

Sono quelli che il corso usa e che servono più spesso a un agente: così Claude li trova già pronti invece di chiederteli a metà lavoro.

  1. Pandoc converte i documenti (Word, PDF, pagine web, testo). FFmpeg lavora su video e audio: taglia, converte, estrae l'audio, riduce il peso. whisper.cpp trascrive in testo le registrazioni e i vocali (il «vocabolario», circa 1,5 GB, lo scarica Claude la prima volta che serve). Node.js serve ad alcuni componenti aggiuntivi di Claude Code. BasicTeX è il motore con cui Pandoc crea i PDF.
  2. Incolla nel Terminale la prima riga del riquadro e premi Invio. Ci vogliono 10–20 minuti: FFmpeg porta con sé molti componenti.
  3. Poi incolla la seconda riga: BasicTeX chiede la password del Mac.
  4. Chiudi e riapri il Terminale e VS Code. Controlla con pandoc --version, ffmpeg -version, node --version e pdflatex --version.
Comando
brew install pandoc ffmpeg whisper-cpp node
brew install --cask basictex

Cosa devi vedere Ogni comando di controllo risponde con un numero di versione.

Se non va
  • «already installed» — Quel programma c'era già: va bene così.
  • «pdflatex: command not found» dopo BasicTeX — Chiudi del tutto il Terminale (⌘ + Q) e riaprilo. Se non basta, riavvia il Mac.
  • L'installazione si ferma con un errore lungo — Copia le ultime righe, incollale a Claude in VS Code chiedendo Cosa è andato storto e come lo sistemo?. Se resta bloccato, scrivi a Stefano.

Con GitHub CLI Claude può salvare e pubblicare il lavoro senza che tu debba scrivere password.

  1. Nel Terminale incolla brew install gh e premi Invio.
  2. Poi scrivi gh auth login e rispondi così: GitHub.com → HTTPS → Yes (authenticate Git) → Login with a web browser.
  3. Il Terminale mostra un codice di 8 caratteri: copialo, premi Invio, incollalo nella pagina che si apre e clicca «Authorize».
  4. Controlla con gh auth status.
Comando
brew install gh
gh auth login

Cosa devi vedere gh auth status risponde «Logged in to github.com account …».

Se non va

Cosa devi vedere Windows 10 o 11, sistema operativo a 64 bit, 4 GB di RAM o più.

Fase 3 Claude Code

Installare Claude Code e collegarlo al proprio abbonamento.

È il comando ufficiale di Anthropic per PowerShell. Claude Code poi si aggiorna da solo.

  1. Incolla il comando in PowerShell e premi Invio. Durante lo scaricamento non si vede nessun avanzamento: aspetta che torni il prompt.
  2. Leggi la fine del messaggio: se compare «Setup notes: … is not in your PATH», vai al primo caso di «Se non va» qui sotto.
  3. Chiudi PowerShell e riaprilo. Scrivi claude --version e premi Invio.
Comando
irm https://claude.ai/install.ps1 | iex

Cosa devi vedere Un numero di versione, per esempio «2.1.226 (Claude Code)».

Se non va
  • «The term 'claude' is not recognized» oppure «Setup notes: … not in your PATH» — La cartella di Claude non è nel PATH (l'elenco dei posti dove Windows cerca i programmi). Incolla queste due righe in PowerShell, chiudi e riapri PowerShell, poi riprova claude --version. In alternativa, a mano: Impostazioni → cerca «variabili d'ambiente» → «Modifica le variabili d'ambiente relative al tuo account» → Path → Modifica → Nuovo → %USERPROFILE%\.local\bin → OK.
    Comando
    $currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')
  • «'irm' is not recognized» — Sei nel Prompt dei comandi, non in PowerShell. Apri PowerShell (passo «Apri PowerShell») e ripeti.
  • «The process cannot access the file … being used by another process» — Un'altra installazione è ancora aperta o l'antivirus sta controllando il file. Chiudi le altre finestre di PowerShell, aspetta un minuto, poi incolla:
    Comando
    Remove-Item -Recurse -Force "$env:USERPROFILE\.claude\downloads"
irm https://claude.ai/install.ps1 | iex
  • «Claude Code does not support 32-bit Windows» — Hai aperto «Windows PowerShell (x86)». Apri quella senza «x86» e ripeti.
  • Scrivendo claude si apre l'app Claude Desktop — Hai una versione vecchia dell'app Claude Desktop: aggiornala all'ultima versione e riprova.

Fonte: code.claude.com/docs/en/troubleshoot-install

Fase 6 Il gestore dei programmi

Il «negozio» dei programmi da riga di comando, e subito i programmi che servono per documenti, PDF, video e audio.

Chocolatey è per Windows quello che Homebrew è per Mac: installa con un comando i programmi da riga di comando che Claude usa per lavorare su documenti, PDF, video e audio.

  1. Premi il tasto Windows, scrivi PowerShell, tasto destro su «Windows PowerShell» → «Esegui come amministratore» → Sì.
  2. Incolla il comando (è una riga sola, lunga: copiala tutta con il pulsante «Copia») e premi Invio. Il comando consente l'esecuzione dello script solo per questa finestra.
  3. Aspetta che finisca, poi chiudi PowerShell, riaprila sempre come amministratore e scrivi choco --version.
Comando
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

Cosa devi vedere choco --version risponde con un numero di versione.

Se non va
  • Errori su «Access denied» o permessi — Non hai aperto PowerShell come amministratore: chiudila e riaprila con «Esegui come amministratore».
  • Errore «running scripts is disabled» o «not digitally signed» — Non hai copiato la riga intera: la parte iniziale «Set-ExecutionPolicy …» serve proprio a questo. Ricopiala con il pulsante «Copia».
  • «choco» non è riconosciuto — Chiudi e riapri PowerShell. Se non basta, riavvia il PC.

Fonte: chocolatey.org/install

Sono quelli che il corso usa e che servono più spesso a un agente: così Claude li trova già pronti invece di chiederteli a metà lavoro.

  1. Pandoc converte i documenti (Word, PDF, pagine web, testo). FFmpeg lavora su video e audio: taglia, converte, estrae l'audio, riduce il peso. whisper.cpp trascrive in testo le registrazioni e i vocali (il «vocabolario», circa 1,5 GB, lo scarica Claude la prima volta che serve). Node.js serve ad alcuni componenti aggiuntivi di Claude Code. MiKTeX è il motore con cui Pandoc crea i PDF.
  2. In PowerShell aperta come amministratore incolla il comando e premi Invio. Ci vogliono 15–30 minuti: MiKTeX e FFmpeg sono grandi.
  3. Chiudi e riapri PowerShell e VS Code. Controlla con pandoc --version, ffmpeg -version, node --version e pdflatex --version.
Comando
choco install pandoc ffmpeg whisper-cpp miktex nodejs-lts -y

Cosa devi vedere Chocolatey chiude con «Chocolatey installed 5/5 packages» (o un numero simile) e ogni comando di controllo risponde con un numero di versione.

Se non va
  • Uno dei pacchetti fallisce e gli altri no — Ripeti il comando solo per quello, per esempio choco install miktex -y. Se fallisce ancora, copia le ultime righe a Claude chiedendo Cosa è andato storto e come lo sistemo?, oppure scrivi a Stefano.
  • «pdflatex» non è riconosciuto — Chiudi tutte le finestre di PowerShell e VS Code e riaprile. Se non basta, riavvia il PC.

Fonte: community.chocolatey.org/packages

Su GitHub si salvano le versioni del lavoro e si pubblicano i tool come pagine web. Il piano gratuito basta.

  2. Se compare «Continue with Google», usalo con il tuo Gmail; altrimenti scrivi l'indirizzo Gmail e scegli una password.

Con GitHub CLI Claude può salvare e pubblicare il lavoro senza che tu debba scrivere password.

  1. In una PowerShell aperta come amministratore incolla choco install gh -y e premi Invio.
  2. Chiudi e riapri PowerShell (normale, non serve più amministratore). Scrivi gh auth login e rispondi così: GitHub.com → HTTPS → Yes (authenticate Git) → Login with a web browser.
  3. PowerShell mostra un codice di 8 caratteri: copialo, premi Invio, incollalo nella pagina che si apre e clicca «Authorize».
  4. Controlla con gh auth status.
Comando
choco install gh -y
gh auth login

Cosa devi vedere gh auth status risponde «Logged in to github.com account …».

Se non va
  • Il browser non si apre — Apri a mano github.com/login/device e incolla il codice.
  • Chocolatey non trova il pacchetto gh — Usa winget, già presente in Windows, in una PowerShell normale:
    Comando
    winget install --id GitHub.cli
